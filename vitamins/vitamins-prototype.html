Smart Supplements Search – Single‑File Prototype

Demo: query → ingredient intent → outcome expansion → value ranking (cost/day to target dose) → explanations. Works offline. Data is a tiny sample dataset you can replace with your own extracted catalog.

Try a scenario

Scenarios preload a query and pick a goal (outcome). You can then tweak the target dose or filters.

What this prototype simulates

  • LLM query understanding → simulated by rules + synonym triggers.
  • Outcome graph → small hardcoded ingredient↔outcome map.
  • Value scoring → cost/day to reach target dose (plus a practicality note).
  • Explanations → assembled from structured fields (no hallucinated numbers).

⚠️ Informational demo only. Not medical advice. Don’t use this prototype to make health decisions.
